# Tous les Types de Flashcards - Exemples en Cardiologie

## 1️⃣ FLASHCARDS BASIQUES (Question/Réponse)

### **Type A: Définition Simple**
```
┌─────────────────────────────────────────┐
│ RECTO                                   │
├─────────────────────────────────────────┤
│ Qu'est-ce que l'insuffisance           │
│ cardiaque?                              │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ VERSO                                   │
├─────────────────────────────────────────┤
│ Incapacité du cœur à assurer un débit  │
│ sanguin suffisant pour répondre aux     │
│ besoins métaboliques de l'organisme.    │
└─────────────────────────────────────────┘
```

```

```

## 9️⃣ FLASHCARDS FORMULE/CALCUL

### **Exemple 1**
```
┌─────────────────────────────────────────┐
│ RECTO                                   │
├─────────────────────────────────────────┤
│ Formule de calcul de la FEVG?          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ VERSO                                   │
├─────────────────────────────────────────┤
│ FEVG = (VTD - VTS) / VTD × 100          │
│                                         │
│ VTD = Volume télédiastolique            │
│ VTS = Volume télésystolique             │
│                                         │
│ Exemple:                                │
│ VTD = 150 mL, VTS = 60 mL               │
│ FEVG = (150-60)/150 × 100 = 60%         │
└─────────────────────────────────────────┘
```

### **Exemple 2**
```
┌─────────────────────────────────────────┐
│ RECTO                                   │
├─────────────────────────────────────────┤
│ Calcul de l'index cardio-thoracique?   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ VERSO                                   │
├─────────────────────────────────────────┤
│ ICT = Diamètre cardiaque / Diamètre    │
│       thoracique                        │
│                                         │
│ Normal: < 0,5                           │
│ Cardiomégalie: ≥ 0,5                    │
└─────────────────────────────────────────┘
```

## 📊 RÉSUMÉ DES TYPES

| Type | Utilisation | Exemple |
|------|-------------|---------|
| **Basique** | Définitions, listes | "Qu'est-ce que l'IC?" |
| **À trous** | Phrases à compléter | "FEVG < [...] = HFrEF" |
| **Inversée** | Double sens | Signes → Diagnostic / Diagnostic → Signes |
| **Image** | Reconnaissance visuelle | ECG, Radio, Echo |
| **Cas clinique** | Application pratique | Vignette → Diagnostic |
| **Comparaison** | Différences | HFrEF vs HFpEF |
| **Mnémotechnique** | Mémorisation | "HI CARD" pour causes |
| **Arbre décision** | Conduite à tenir | FEVG → Traitement |
| **Formule** | Calculs | FEVG = (VTD-VTS)/VTD |
| **Séquence** | Algorithmes | Démarche diagnostique |

## 🎯 NOTRE RECOMMANDATION

Pour votre plateforme, nous suggérons un **mix intelligent**:

1. **Questions basiques** (70%) - Rapides, efficaces
2. **Cas cliniques** (20%) - Application pratique
3. **Images** (10%) - Reconnaissance visuelle

**Mais organisées de manière progressive** (du simple au complexe), pas aléatoire comme Anki!

C'est mieux que des flashcards isolées! 🚀
